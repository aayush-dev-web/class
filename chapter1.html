1.1 Introduction of Computer

1.1.1 Definition, Characteristics and Application of Computer

A computer is an electronic device that accepts data as input, processes the data by performing arithmetic and logical operations according to a set of instructions (a program), and produces meaningful information as output. Computers can store, retrieve and process data at very high speed.


Characteristics of Computer:

  • Speed - A computer can perform millions of instructions per second.
  • Accuracy - Computers give accurate results if correct data and instructions are given.
  • Diligence - A computer can work continuously for hours without getting tired.
  • Storage Capacity - Computers can store a huge amount of data permanently.
  • Versatility - A computer can perform many different types of tasks.
  • Automation - Once a program is given, the computer works automatically.
  • No I.Q. of its own - A computer cannot think by itself; it works as per instructions.

Applications of Computer:

1.1.5 Mobile Computing and its Application

Mobile computing refers to the technology that allows transmission of data, voice and video via a computing device without being connected to a fixed physical link. It uses portable devices such as smartphones, tablets and laptops connected through wireless networks.


Applications of Mobile Computing:

  • Mobile banking and online payment (e.g. e-sewa, mobile banking apps)
  • Global Positioning System (GPS) navigation
  • Video conferencing and social networking on the go
  • Mobile learning (m-learning)
  • Emergency services and healthcare monitoring

1.2 Computer System and I/O Devices

1.2.1 Concept of Computer Architecture and Organization

Computer Architecture refers to the conceptual design and the functional structure of a computer system - i.e. what the computer does (instruction sets, addressing modes, data types). Computer Organization refers to the way the hardware components are connected together to form a computer system - i.e. how the computer does it (control signals, memory interfacing, peripherals).

1.2.2 Components of Computer System

A computer system is made up of the following major components:

  • Input Unit - accepts data and instructions from the user
  • Central Processing Unit (CPU) - processes data (Control Unit + ALU + Registers)
  • Memory Unit - stores data and instructions temporarily or permanently
  • Output Unit - displays or presents the processed information

1.2.3 Microprocessor

A microprocessor is a single integrated circuit (IC / chip) that contains the entire Central Processing Unit of a computer. It performs arithmetic, logical, control and input/output operations specified by the instructions stored in memory.


Parts of a Microprocessor:

PartFunction
Control Unit (CU)Directs and coordinates the operations of the whole computer
Arithmetic Logic Unit (ALU)Performs arithmetic (add, subtract) and logical (compare) operations
RegistersSmall, high speed storage locations inside the CPU used to hold data temporarily

Clock Speed: The clock speed of a microprocessor is the rate at which it can execute instructions, measured in Hertz (Hz), MHz, or GHz. A higher clock speed generally means the processor can complete more cycles (and hence more instructions) per second. For example, a processor with a clock speed of 3.5 GHz completes 3.5 billion cycles every second.

Word Length: The word length of a processor is the number of bits it can process or transfer in one operation, such as 8-bit, 16-bit, 32-bit, or 64-bit. A larger word length allows the processor to handle more data at once, increasing performance. Most modern personal computers use 64-bit processors.

1.2.4 Bus System

A bus is a set of parallel wires that connects the various components of a computer and allows transfer of data between them.

Type of BusFunction
Data BusCarries actual data between CPU, memory and I/O devices
Address BusCarries the memory address to identify the location of data
Control BusCarries control signals like read, write, and interrupt signals

1.2.5 Primary Memory

Primary memory (main memory) is directly accessible by the CPU and is used to store data and instructions currently being processed. It is generally volatile (except ROM).


RAM (Random Access Memory): A volatile memory that stores data and programs currently being used by the CPU. Data is lost when power is switched off.

Type of RAMDescription
SRAM (Static RAM)Faster, more expensive, used in cache memory, does not need refreshing
DRAM (Dynamic RAM)Slower, cheaper, used as main memory, needs to be refreshed periodically

ROM (Read Only Memory): A non-volatile memory that permanently stores instructions needed to start the computer (e.g. BIOS). Data is not lost when power is off.

Type of ROMDescription
MROMMasked ROM - programmed by the manufacturer, cannot be changed
PROMProgrammable ROM - can be programmed once by the user
EPROMErasable PROM - can be erased using ultraviolet light and reprogrammed
EEPROMElectrically Erasable PROM - can be erased and reprogrammed electrically

Comparison: RAM vs ROM

Cache Memory: A very fast, small memory placed between the CPU and main memory. It stores frequently used data and instructions so the CPU does not have to wait for slower main memory, thus increasing overall speed.

Buffer: A temporary storage area, usually in RAM, used to hold data while it is being transferred between two devices operating at different speeds (e.g. between a printer and the computer).

CHAPTER SUMMARY

A computer is an electronic device that accepts input, processes it as per given instructions, and produces output. Computer technology has evolved through five generations, from vacuum tubes to artificial intelligence based systems. Computers exist in different sizes and power levels - supercomputers, mainframes, minicomputers, and microcomputers - and are increasingly used through mobile computing. A complete computer system is built from an input unit, a CPU (control unit, ALU and registers), a memory unit and an output unit, all connected through a bus system. Memory is divided into primary memory (RAM, ROM, cache) which is fast but limited, and secondary memory (hard disk, pen drive, optical disks) which is slower but has larger, permanent storage. Various input devices (keyboard, mouse, scanner, OMR, OCR, BCR, MICR, etc.) are used to enter data, while output devices (monitor, printer, speaker) present processed information. Hardware interfaces such as USB and HDMI are used to physically connect these devices to the computer.

IMPORTANT POINTS

  • Speed of a processor is measured in Hz/MHz/GHz or MIPS; storage is measured in bits and bytes (1 Byte = 8 Bits, 1 KB = 1024 Bytes).
  • RAM is volatile; ROM is non-volatile.
  • Cache memory sits between the CPU and RAM to speed up processing.
  • MICR is mainly used in banks; OMR is mainly used to check exam answer sheets; BCR is used in shops to read barcodes.
  • SSDs are faster and more durable than traditional HDDs because they have no moving parts.
