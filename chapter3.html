CHAPTER 3

COMPUTER SOFTWARE AND OPERATING SYSTEM

3.1 Concept of Software

Software is a set of programs, instructions and data that tells a computer how to perform a specific task. Unlike hardware, software cannot be touched; it is intangible.

Types of Software:

TypeDescriptionExample
System SoftwareControls and manages the hardware so that application software can runWindows, Linux, Device Drivers
Utility SoftwarePerforms maintenance tasks and helps keep the computer running smoothlyAntivirus, Disk Cleanup, File Compression Tools
Application SoftwareDesigned to help users perform specific tasksMS Word, MS Excel, Photo Editor
Web-based SoftwareRuns on a web browser and is accessed over the internetGoogle Docs, Gmail, online banking
Mobile ApplicationsSoftware designed specifically to run on mobile devicesWhatsApp, Instagram, mobile banking apps

3.2 Operating System

Introduction

An Operating System (OS) is system software that acts as an interface between the user and the computer hardware. It manages hardware resources and provides services for application programs to run.

Need for Operating System

A computer's hardware alone cannot understand what the user wants to do. The operating system is needed because it:

  • Provides a way for the user to communicate with the hardware without knowing complex machine-level instructions
  • Allows multiple programs and users to share hardware resources like the CPU and memory efficiently
  • Manages and coordinates all input, output and storage devices
  • Provides a platform on which application software can run

Role of Operating System

  • Manages the computer's memory, processor and storage
  • Provides a user interface (GUI or command line) to interact with the computer
  • Manages files and folders
  • Handles input and output devices
  • Provides security through user accounts and passwords

Functions of Operating System

FunctionDescription
Process ManagementCreates, schedules and terminates processes running in the computer
Memory ManagementAllocates and deallocates memory space to programs as needed
File ManagementOrganizes, stores, retrieves and protects files
Device ManagementControls and coordinates input/output devices through drivers
Security ManagementProtects data and system resources from unauthorized access

Operating System Terminology

TermDescription
MultiprogrammingAbility of an OS to keep multiple programs in main memory and execute them by switching the CPU between them
MultitaskingAbility of an OS to allow a user to perform more than one task at the same time (e.g. browsing while listening to music)
MultiprocessingUse of two or more CPUs within a single computer system to execute programs simultaneously
Distributed Operating SystemAn OS that manages a group of independent computers connected over a network and makes them appear as a single system to the user

3.3 Windows Operating System

Windows is a GUI-based (Graphical User Interface) operating system developed by Microsoft. It allows users to interact with the computer using icons, windows, menus and a pointer (mouse) rather than typing text commands.


Features of Windows OS

  • User-friendly graphical interface
  • Supports multitasking
  • Plug and Play support for hardware devices
  • Built-in security features like Windows Defender and firewall
  • Support for a wide range of application software

Windows Environment

File ExplorerA file management application used to browse, open, copy, move and delete files/folders
Files and FoldersA file stores data; a folder (directory) is used to organize related files together
Start Screen / Start MenuProvides access to installed programs, settings and the search function
Desktop CustomizationAllows changing wallpaper, themes, icon size and screen resolution
Installing/Removing DevicesWindows uses "Device Manager" to install, update or remove hardware device drivers
PasswordsUsed to protect user accounts from unauthorized access
Privacy SettingsControl what data apps and websites can access, such as location or camera

System ToolsUtilities like Disk Cleanup, Disk Defragmenter and Task Manager used to maintain the system
AccessoriesSmall built-in programs such as Notepad, Paint, Calculator and WordPad

3.4 Open Source and Mobile Operating System

Open Source Concept

Open source software is software whose source code is made freely available for anyone to view, modify, and distribute. It encourages collaborative development and is usually free of cost.

Advantages of Open Source Software:

  • Usually free or low cost to obtain and use
  • Source code can be studied, modified and improved by anyone
  • Large community support helps fix bugs and security issues quickly
  • Not dependent on a single company - reduces vendor lock-in

Linux

Linux is a free and open source operating system based on UNIX. It is widely used in servers, supercomputers and personal computers because it is stable, secure and customizable.


UNIX

UNIX is a powerful, multiuser, multitasking operating system developed in the 1970s. It was the foundation for many modern operating systems, including Linux and macOS.

Linux Distributions

Mobile Operating System

A Mobile Operating System is software that manages the hardware and software resources of mobile devices such as smartphones and tablets.

CHAPTER SUMMARY

Software is the set of programs that instructs a computer what to do, and is broadly classified as system software, utility software, application software, web-based software and mobile applications. The operating system is the most important system software - it acts as an interface between the user and the hardware, managing processes, memory, files, devices and security. Modern operating systems support multiprogramming, multitasking, multiprocessing and distributed processing. Windows is a widely used GUI-based operating system with features like File Explorer, Control Panel and desktop customization. Linux and UNIX are open source alternatives which are free, customizable and community supported. Mobile operating systems such as Android and iOS manage the hardware and software of smartphones and tablets.

KEY TERMS

TermMeaning in Brief

GUIGraphical User Interface - interaction using icons and windows instead of text commands
MultitaskingRunning more than one task at the same time
Open SourceSoftware whose source code is freely available to view and modify
DistributionA packaged version of the Linux OS with its own set of tools and software

IMPORTANT POINTS

  • System software works closely with hardware; application software works closely with the user's tasks.
  • Multiprogramming is about keeping several programs in memory; multitasking is about a user performing multiple tasks at once; multiprocessing uses multiple physical CPUs.
  • Linux is open source and free; Windows is proprietary (closed source) and usually paid.
  • Android (based on Linux) is open source; iOS is closed source and used only on Apple devices.
