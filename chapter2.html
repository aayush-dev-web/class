2.1 Number System and Conversion

A number system is a way of representing numbers using a set of symbols. The number of symbols used is called the base or radix of the number system.

Decimal to Binary Conversion

Divide the decimal number repeatedly by 2 and note the remainders from bottom to top.

Example: Convert (25)10 to binary.

25 / 2 = 12  remainder 1
12 / 2 = 6   remainder 0
6  / 2 = 3   remainder 0
3  / 2 = 1   remainder 1
1  / 2 = 0   remainder 1

Reading remainders from bottom to top: 11001

Answer: (25)10 = (11001)2

Binary to Decimal Conversion

Multiply each binary digit by 2 raised to the power of its position (starting from 0 on the right) and add the results.

Example: Convert (11001)2 to decimal.

1x2^4 + 1x2^3 + 0x2^2 + 0x2^1 + 1x2^0
= 16 + 8 + 0 + 0 + 1
= 25

Answer: (11001)2 = (25)10

Decimal to Octal Conversion

Example: Convert (100)10 to octal.

100 / 8 = 12  remainder 4
12  / 8 = 1   remainder 4
1   / 8 = 0   remainder 1

Reading remainders bottom to top: 144

Answer: (100)10 = (144)8

Octal to Decimal Conversion

Example: Convert (144)8 to decimal.

1x8^2 + 4x8^1 + 4x8^0
= 64 + 32 + 4
= 100

Answer: (144)8 = (100)10

Decimal to Hexadecimal Conversion

Example: Convert (255)10 to hexadecimal.

255 / 16 = 15  remainder 15 (F)
15  / 16 = 0   remainder 15 (F)

Reading remainders bottom to top: FF

Answer: (255)10 = (FF)16

Hexadecimal to Decimal Conversion

Example: Convert (FF)16 to decimal.

Fx16^1 + Fx16^0
= 15x16 + 15x1
= 240 + 15
= 255

Answer: (FF)16 = (255)10

Binary to Octal Conversion

Group the binary digits into sets of 3 starting from the right, then convert each group.

Example: Convert (11001)2 to octal.

011  001
 3    1

Answer: (11001)2 = (31)8

Octal to Binary Conversion

Convert each octal digit into its 3-bit binary equivalent.

Example: Convert (31)8 to binary.

3 = 011
1 = 001

Answer: (31)8 = (011001)2 = (11001)2

Binary to Hexadecimal Conversion

Group the binary digits into sets of 4 starting from the right, then convert each group.

Example: Convert (11111111)2 to hexadecimal.

1111  1111
 F      F

Answer: (11111111)2 = (FF)16

Hexadecimal to Binary Conversion

Convert each hexadecimal digit to its 4-bit binary equivalent.

Example: Convert (FF)16 to binary.

F = 1111
F = 1111

Answer: (FF)16 = (11111111)2

One's Complement

The 1's complement of a binary number is obtained by changing every 0 to 1 and every 1 to 0.

Example: 1's complement of 1010 = 0101

Subtraction using 1's Complement

Example: Subtract (0101)2 from (1101)2 using 1's complement

Step 1: Find 1's complement of 0101 -> 1010

Step 2: Add it to 1101
    1101
  + 1010
  -------
   10111   (there is a carry out)

Step 3: Add the carry (end-around carry) to the result
    0111
  +    1
  -------
    1000

Answer: 1101 - 0101 = 1000

Two's Complement

The 2's complement of a binary number is obtained by adding 1 to its 1's complement.

Example: 2's complement of 1010

1's complement of 1010 = 0101
Add 1              = 0101 + 1 = 0110

Answer: 2's complement of 1010 = 0110

Subtraction using 2's Complement

Example: Subtract (0101)2 from (1101)2 using 2's complement

Step 1: Find 2's complement of 0101
  1's complement = 1010
  Add 1          = 1011  (this is the 2's complement)

Step 2: Add it to 1101
    1101
  + 1011
  -------
   11000   (discard the final carry)

Answer: 1101 - 0101 = 1000

2.2 Logic Function and Boolean Algebra

Boolean Algebra is a branch of mathematics that deals with binary variables and logic operations. It was developed by George Boole and is the basis of digital logic circuit design.

Boolean Variable: A symbol (such as A, B, C) that can take only one of two possible values - 0 (False) or 1 (True) - used to represent a logical quantity.

Boolean Constant: A fixed logical value, either 0 (False) or 1 (True), used directly in a Boolean expression.

Boolean Values: Boolean algebra uses only two values - TRUE (1) and FALSE (0).

Truth Table: A table that shows all possible combinations of input values and their corresponding output for a logic operation or circuit.

Boolean Expression: A mathematical expression that uses Boolean variables (like A, B) and logic operators (AND, OR, NOT) to represent a logical statement. Example: Y = A.B + C

Boolean Function: A function that takes Boolean inputs and produces a Boolean output based on a Boolean expression.

CHAPTER SUMMARY

Computers work internally using the binary number system, but for human convenience, data can also be expressed in decimal, octal, and hexadecimal systems, and can be converted between them using division-remainder and grouping methods. Binary arithmetic (addition and subtraction) forms the basis of all computer calculations, and complement methods (1's complement and 2's complement) allow subtraction to be performed using addition circuits only, which simplifies computer hardware design. Boolean algebra, based on the values 0 and 1, is used to design and analyze digital logic circuits using logic gates - AND, OR, NOT, NAND, NOR, XOR and XNOR - each represented by a truth table. Boolean laws such as identity, null, idempotent, complement, involution, commutative, associative and distributive laws are used to simplify Boolean expressions and can be verified using truth tables.

IMPORTANT POINTS

  • To convert binary to octal, group bits in sets of 3; to convert binary to hexadecimal, group bits in sets of 4 (from the right).
  • 2's complement subtraction discards the final carry, while 1's complement subtraction adds the final carry back (end-around carry).
  • AND and OR are called basic gates; NOT is called the complement/inverter gate; NAND and NOR are called universal gates because any other gate can be built using only NAND gates or only NOR gates.
  • XOR gives 1 when inputs are different; XNOR gives 1 when inputs are the same.
