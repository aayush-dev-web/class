5.1 Programming Concept

Introduction to Programming Languages

A programming language is a set of rules and symbols used to write instructions that a computer can understand and execute.

TypeDescriptionExample
Low-level LanguageClose to machine code, hard for humans to understand but fast for the machine (Machine Language, Assembly Language)Assembly Language
High-level LanguageClose to human language (English-like), easy to write, read and maintainC, C++, Java, Python
4GL (Fourth Generation Language)Very high level languages designed for a specific purpose such as database queries, requiring fewer lines of codeSQL

Translators (Language Processors):

TermDescription
CompilerTranslates the entire high-level source code into machine code at once before execution
InterpreterTranslates and executes source code line by line
AssemblerTranslates assembly language code into machine code

Types of Errors:

Error TypeDescription
Syntax ErrorOccurs when the rules (grammar) of the programming language are violated, e.g. missing semicolon
Semantic ErrorOccurs when a statement is syntactically correct but does not do what was intended
Runtime ErrorOccurs while the program is running, e.g. division by zero

Program Control Structures

StructureDescription
SequenceInstructions are executed one after another in the order they are written
SelectionA decision is made and one of two or more paths is chosen (if, if-else, switch)
IterationA set of instructions is repeated as long as a condition is true (loops)

Algorithm: A step-by-step set of instructions written in plain language to solve a problem.

Example Algorithm - to find the sum of two numbers:

Step 1: Start
Step 2: Read A and B
Step 3: Sum = A + B
Step 4: Print Sum
Step 5: Stop

Flowchart: A diagrammatic representation of an algorithm using standard symbols (Oval for start/stop, Parallelogram for input/output, Rectangle for process, Diamond for decision).

Pseudocode: An informal, English-like way of describing an algorithm without following the strict syntax of any programming language.

BEGIN
  READ A, B
  SUM = A + B
  PRINT SUM
END

Data Representation

TermDescription
BinaryData representation using only 0s and 1s, the basic language of computers
BCD (Binary Coded Decimal)A coding system where each decimal digit is represented separately by a 4-bit binary code
ASCIIAmerican Standard Code for Information Interchange - a 7/8-bit character encoding standard used to represent text (128/256 characters)
UnicodeA universal character encoding standard that can represent characters from almost all writing systems in the world using 16 or more bits

5.2 C Programming Language

Introduction and Features of C

C is a general-purpose, structured, high-level programming language developed by Dennis Ritchie in 1972 at Bell Labs.

  • Simple and easy to learn
  • Structured programming language
  • Fast execution speed
  • Portable - programs can run on different machines with little or no change
  • Rich set of built-in operators and functions
  • Forms the base for many modern languages like C++, Java, and C#

Structure of a C Program

#include <stdio.h>      /* Preprocessor Directive */

int main()               /* Main function - execution starts here */
{
    /* statements */
    printf("Hello, World!");
    return 0;
}

C Preprocessor: A program that processes the source code before it is compiled, handling directives that begin with '#' such as #include and #define.

Header Files: Files that contain declarations of built-in functions, included using #include. Example: stdio.h (standard input output), string.h (string functions).

Character Set: The set of valid characters that a C compiler can recognize - letters (A-Z, a-z), digits (0-9), special symbols (+, -, *, /, {, } etc.) and white spaces.

Comments: Non-executable text used to explain code, ignored by the compiler. Example: /* this is a comment */ or // single line comment

Identifiers: Names given to variables, functions and arrays by the programmer, e.g. total, sum1.

Keywords: Reserved words that have a special, predefined meaning in C and cannot be used as identifiers. Examples: int, float, if, else, while, for, return

Tokens: The smallest individual units of a C program - keywords, identifiers, constants, strings and operators.

Basic Data Types

Data TypeDescriptionExample
intStores whole numbers10, -5
floatStores decimal (real) numbers3.14
charStores a single character'A'
doubleStores double precision decimal numbers3.14159265

Constants: Values that do not change during program execution, e.g. const int PI = 3.14;

Variables: Named memory locations used to store data that can change during execution, e.g. int age;

Type Specifiers: Keywords used to declare the type of a variable, such as int, float, char, double.

Simple Statement: A single instruction ending with a semicolon, e.g. a = a + 1;

Compound Statement: A group of statements enclosed in curly braces { } treated as one block, commonly used with if, for, while.

Arrays

An array is a collection of elements of the same data type stored in contiguous memory locations and referred to by a single name.

Declaration: int marks[5]; declares an array named marks that can hold 5 integers, indexed from marks[0] to marks[4].

Initialization: int marks[5] = {70, 65, 80, 90, 55}; declares and fills the array with values at the same time.

One Dimensional (1D) Array:

#include <stdio.h>
int main()
{
    int marks[5] = {70, 65, 80, 90, 55};
    int i;
    for (i = 0; i < 5; i++)
    {
        printf("%d\n", marks[i]);
    }
    return 0;
}

Expected Output:

70
65
80
90
55

Two Dimensional (2D) Array:

#include <stdio.h>
int main()
{
    int a[2][2] = {{1,2},{3,4}};
    int i, j;
    for (i = 0; i < 2; i++)
    {
        for (j = 0; j < 2; j++)
        {
            printf("%d ", a[i][j]);
        }
        printf("\n");
    }
    return 0;
}

Expected Output:

1 2
3 4

Matrix Addition:

#include <stdio.h>
int main()
{
    int a[2][2] = {{1,2},{3,4}};

    {
        for (j = 0; j < 2; j++)
            printf("%d ", c[i][j]);

    }

}

Sum Matrix:

10 12

Matrix Subtraction:

#include <stdio.h>
int main()
{
    int a[2][2] = {{5,6},{7,8}};
    int b[2][2] = {{1,2},{3,4}};

}

Difference Matrix:
4 4
4 4

Strings in C

A string is an array of characters terminated by a null character '\0'.

Declaration: char name[20]; declares a character array that can hold up to 19 characters plus the null terminator.

Initialization: char name[20] = "Nepal"; declares and stores the string "Nepal" in the array at the same time.

FunctionPurpose
strlen()Finds the length of a string
strcat()Joins (concatenates) two strings
strcmp()Compares two strings
strrev()Reverses a string
strcpy()Copies one string into another
strlwr()Converts a string to lowercase
strupr()Converts a string to uppercase

Example Program using String Functions:

#include <stdio.h>
#include <string.h>
int main()
{
    char str1[20] = "Nepal";
    char str2[20] = "Computer";

    printf("Length of str1: %d\n", strlen(str1));

    strcat(str1, str2);
    printf("After strcat: %s\n", str1);

    if (strcmp(str1, str2) == 0)
        printf("Strings are equal\n");
    else
        printf("Strings are not equal\n");

    strupr(str2);
    printf("Uppercase: %s\n", str2);

    strlwr(str2);
    printf("Lowercase: %s\n", str2);

    return 0;
}

Expected Output:

Length of str1: 5
After strcat: NepalComputer
Strings are not equal
Uppercase: COMPUTER
Lowercase: computer

Note: strupr() and strlwr() are supported in the Turbo C compiler commonly used for NEB practicals; in some modern compilers they may need to be written manually using a loop and toupper()/tolower() from ctype.h.
