CHAPTER 6

WEB TECHNOLOGY I

6.1 Introduction to Web Development

Web development is the process of building, creating and maintaining websites. It includes web design, web publishing, web programming and database management.

6.2 Web Browsers and Search Engines

A web browser is application software used to access and view websites on the internet.

Web BrowserDeveloper
Google ChromeGoogle
Mozilla FirefoxMozilla Foundation
Microsoft EdgeMicrosoft
SafariApple

A search engine is a web-based tool that allows users to search for information on the internet using keywords. Examples: Google, Bing, Yahoo.

6.3 Internet and Web Technologies

The Internet is a global network that connects millions of computers, allowing them to communicate and share information. The World Wide Web (WWW) is a system of interlinked documents (web pages) accessed via the internet using a browser.

6.4 Content Management System

A Content Management System (CMS) is software that allows users to create, manage and modify content on a website without needing specialized technical/coding knowledge. Examples: WordPress, Joomla, Drupal.

6.5 HTML: The Language of the Web

HTML (HyperText Markup Language) is the standard markup language used to create the structure and content of web pages using elements called tags.

Objectives of HTML:

  • To structure content on the web (headings, paragraphs, lists, tables)
  • To create links between different web pages (hyperlinks)
  • To embed images, audio, video and other media in a web page
  • To create forms for collecting user information

Structure of an HTML Document:

<html>
<head>
<title>Page Title</title>
</head>
<body>
   Page content goes here...
</body>
</html>

Publishing and Hosting: After a website is created, it needs a domain name (a readable web address, e.g. www.example.com) and web hosting (server space that stores the website files and makes them accessible over the internet) to be published on the web.

HTML Tags vs Attributes: A tag defines an element, e.g. <p>. An attribute provides additional information about a tag and is written inside the opening tag, e.g. <body bgcolor="yellow"> - here bgcolor is an attribute.

Headings

HTML provides six levels of headings, <h1> (largest/most important) to <h6> (smallest). The align attribute can be set to left, right, or center.

Address Tag

<address>
Kathmandu, Nepal<br>

The <address> tag is used to define contact information for the author or owner of a document, usually displayed in italics.

Links (Hyperlinks and Anchors)

<a href="chapter1.html">Link to another HTML document</a>
<a href="notes.pdf">Link to another data object</a>
<a href="#section2">Link to a place in the same document</a>
<a href="chapter2.html#topic">Link to a place in another document</a>
<a name="section2">Section 2</a>

The <a> (anchor) tag creates a hyperlink. The href attribute specifies the destination, which can be another HTML page, a file, or a bookmark (anchor) within the same or a different document.

HTML5 Graphics Tags

<canvas id="myCanvas" width="200" height="100"></canvas>

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" />
</svg>

<canvas> is used (with JavaScript) to draw graphics on the fly, while <svg> (Scalable Vector Graphics) is used to define vector-based graphics directly in HTML.

Domain Name and Web Hosting

A domain name is a readable address used to identify a website on the internet (e.g. neb.gov.np). Web hosting is a service that stores website files on a server and makes the website accessible on the internet.

Introduction to CSS

CSS (Cascading Style Sheets) is a language used to describe the presentation (colors, fonts, layout) of an HTML document.

Type of CSSDescription
Inline CSSApplied directly to a single HTML element using the style attribute
Embedded (Internal) CSSWritten inside a <style> tag in the head section of the HTML document
External CSSWritten in a separate .css file and linked to the HTML document
